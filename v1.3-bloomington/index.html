Prototype v1.3 Bloomington IA

The v1.3 navigation prototypes with the IU Bloomington site’s navigation. These pages are for review. They are not live university websites.

What is different from v1.3

The designs are the same as Prototype v1.3. Only the site inside them changed.

  • Navigation. The menu is the one on bloomington.iu.edu: 8 main sections and 228 pages, with the same names and order.
  • Page content. Each page keeps its real headline and breadcrumbs. The rest is cream placeholder boxes.
  • Page length. Each page is as long as the real Bloomington page, measured on a desktop screen.
  • Header buttons. Removed. The Bloomington header has none.
